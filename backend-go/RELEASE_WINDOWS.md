# 发布窗口策略

## 原则

1. 每服务独立发布窗口，避免全链路耦合发布。
2. 高风险改动必须在低峰时段发布。
3. 发布必须带回滚命令与观察指标。

## 建议窗口（UTC+8）

1. `api-gateway`: 工作日 10:00-12:00, 15:00-17:00
2. `detection-service`: 工作日 14:00-16:00（模型联动改动优先）
3. `report-service`: 工作日 10:00-12:00
4. `governance-service`: 工作日 16:00-18:00

## 发布检查清单

1. 目标服务 SLO 与告警正常
2. 数据迁移脚本已演练
3. 回滚步骤可在 10 分钟内执行
