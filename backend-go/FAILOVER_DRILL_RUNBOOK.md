# 故障演练 Runbook

## 场景 1：下游服务不可达

1. 将 `detection-service` 端口临时关闭。
2. 验证网关告警与熔断触发。
3. 验证 `MICROSERVICE_MODE=strict` 下无本地回退。
4. 记录恢复耗时与错误峰值。

## 场景 2：Redis 事件总线不可达

1. 停止 Redis。
2. 验证 `EVENT_BUS_REQUIRED=false` 时降级到日志发布。
3. 验证 outbox 状态与重试行为。

## 场景 3：数据库连接异常

1. 临时撤销服务数据库账号权限。
2. 验证 `/ready` 失败与告警触发。
3. 恢复权限后验证恢复时间。

## 复盘模板

1. 触发时间线
2. 影响范围
3. 发现与恢复路径
4. 改进项与 owner
